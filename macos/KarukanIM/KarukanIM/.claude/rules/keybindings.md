# Key Bindings Reference

| Key | Action |
|-----|--------|
| Space | Convert / next candidate |
| Tab | Next candidate |
| Enter | Commit |
| Escape | Cancel / revert |
| Ctrl+J | Force hiragana |
| Ctrl+K | Force katakana |
| Ctrl+; | Force ASCII |
| Ctrl+I / Shift+Left | Shrink segment |
| Ctrl+O / Shift+Right | Extend segment |
| Ctrl+Shift+L | Toggle live conversion |
| JIS Kana (keyCode 104) | Activate |
| JIS Eisu (keyCode 102) | Deactivate + commit |
